# Claude Code Companion

Расширение VS Code без зависимостей (`lekra.claude-companion`), которое добавляет возможности, отсутствующие в официальном расширении **Claude Code** (`anthropic.claude-code`):

- **статусы сессий в статус-баре** — `~` работа идёт, `?` ждёт вас, `V` выполнено, `!` ошибка, с числом сессий в каждом состоянии. Клик открывает меню сессий этого окна; выбор пункта фокусирует вкладку Claude.
- **статусы в названиях вкладок** — `[~] Fix parser`, `[?] …`, `[V] …`, `[!] …` перед названием каждой вкладки Claude Code (см. [Статусы во вкладках](#статусы-во-вкладках)).
- **звуки для «выполнено / ждёт / ошибка»** — короткий восходящий сигнал из двух нот в конце хода, мягкий двойной пинг, когда Claude ждёт разрешения или ответа, и нисходящий тон при ошибке. Сигнал завершения играет только для ходов длительностью не меньше `doneSoundMinSeconds` (20 с по умолчанию), поэтому быстрые вопросы проходят молча.
- **лимиты подписки Claude** — 5-часовой и 7-дневный (плюс дополнительная недельная корзина, если API её отдаёт) с графической полоской, темпом («в графике» / «медленнее» / «быстрее»), прогнозом исчерпания, обратным отсчётом до сброса и пороговыми уведомлениями. Обновление каждые 5 минут и вскоре после завершения хода.
- **баланс DeepSeek и расход воркеров** — баланс с `api.deepseek.com` и расход за сегодня / последние 7 дней из журнала `ds.py` (`~/.claude/deepseek-ledger.jsonl`).
- **предупреждение о размере контекста** — однократное уведомление, когда контекст сессии достигает `contextWarnTokens` (по умолчанию 300 000).
- **переключатель маршрутизации DeepSeek** — меню по клику на статус-бар и подсказка показывают, идут ли новые чаты Claude через `api.deepseek.com`, и переключают это одним кликом. Переключатель запускает скрипт `claude-ds`, которому принадлежат ключ, резервные копии и защита `.gitignore`, — сам Companion этот секрет не пишет.
- **вложенные сессии игнорируются** — воркеры DeepSeek и запуски `claude -p` из инструмента Bash выставляют `CLAUDECODE`; расширение не показывает их в статус-баре (включается настройкой `trackNestedSessions`).

Всё локализовано на язык интерфейса VS Code (английский, русский, упрощённый китайский).

## Как это работает

Статусы берутся из собственных HTTP-хуков Claude Code; единственная правка расширения Claude — необязательная врезка для названий вкладок (ниже).

1. Пока открыто хотя бы одно окно VS Code, расширение записывает HTTP-хуки в `~/.claude/settings.json` (с учётом `CLAUDE_CONFIG_DIR`) для событий `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PermissionRequest`, `Notification`, `Elicitation`, `Stop`, `StopFailure` и `SessionEnd`. Все посторонние настройки, хуки и ключи верхнего уровня остаются нетронутыми; файл, который не удаётся разобрать, никогда не перезаписывается — о нём сообщается ошибка.
2. Все окна пытаются занять `127.0.0.1:47823` (настройка `claudeCompanion.port`). Первое становится **лидером**, остальные — ведомыми и повторяют попытку каждые 3 секунды. URL хуков всегда указывает на лидера.
3. Запросы хуков несут в заголовках идентификатор окна-владельца и флаг `CLAUDECODE` (вложенная сессия). Лидер хранит общее состояние сессий в глобальном хранилище расширения, все окна читают его оттуда.
4. Названия сессий и размер контекста берутся из хвоста файлов транскриптов Claude Code — само расширение Claude при этом не читается.
5. Когда закрывается последнее окно VS Code, хуки удаляются: иначе CLI печатал бы «hook failed» на каждое событие, пока Companion не слушает. Удаление расширения тоже убирает хуки.

Лимиты Claude запрашиваются у `https://api.anthropic.com/api/oauth/usage` с OAuth-токеном, который уже хранит Claude Code. Данные DeepSeek идут напрямую в `https://api.deepseek.com` (без прокси). См. [Приватность](#приватность).

## Статусы во вкладках

VS Code не даёт одному расширению менять названия вкладок другого, поэтому компаньон вставляет две маленькие врезки в `extension.js` расширения Claude Code (первая нетронутая копия сохраняется как `extension.js.bak-claude-companion`). Правка ставится целиком или не ставится вовсе и восстанавливается сама: проверяется при каждом запуске и при изменении набора расширений, так что после обновления Claude Code она ставится заново автоматически, и VS Code просит **одну перезагрузку окна**. Если новая версия Claude изменит этот код до неузнаваемости, статусы во вкладках отключатся с одним предупреждением, а всё остальное продолжит работать. Без компаньона изменённый код просто показывает обычное название. Отключается настройкой `claudeCompanion.tabStatusMarkers`.

## Настройки

| Настройка | По умолчанию | Описание |
|---|---|---|
| `claudeCompanion.statusBar` | `true` | Показывать значок Companion в статус-баре. |
| `claudeCompanion.tabStatusMarkers` | `true` | Показывать статус сессии перед названием вкладки Claude Code (правит расширение Claude, см. выше). |
| `claudeCompanion.sessionStatus` | `true` | Показывать счётчики сессий по статусам (`~` работа идёт, `?` ждёт вас, `V` выполнено, `!` ошибка). |
| `claudeCompanion.usageInStatusBar` | `true` | Показывать проценты использования лимитов на 5 часов и 7 дней в статус-баре. |
| `claudeCompanion.soundDone` | `true` | Восходящий сигнал при завершении хода. |
| `claudeCompanion.soundWaiting` | `true` | Двойной пинг, когда Claude ждёт вас. |
| `claudeCompanion.soundError` | `true` | Нисходящий тон при ошибке хода. |
| `claudeCompanion.doneSoundMinSeconds` | `20` | Минимальная длительность хода для сигнала завершения; более короткие ходы молчат (`0` = играть всегда). |
| `claudeCompanion.notifications` | `false` | Нативное уведомление VS Code с названием сессии при завершении хода. |
| `claudeCompanion.alerts` | `true` | Уведомлять, когда лимит Claude или баланс DeepSeek пересекает порог (один раз за окно лимита). |
| `claudeCompanion.alertThreshold5h` | `0.8` | Порог для 5-часового лимита (доля `0..1`). |
| `claudeCompanion.alertThreshold7d` | `0.9` | Порог для 7-дневного лимита (доля `0..1`). |
| `claudeCompanion.alertDeepseekBelowUsd` | `1` | Предупреждать, когда баланс DeepSeek опускается ниже этой суммы (USD); повторно — после роста до 1,5 порога. |
| `claudeCompanion.contextWarnTokens` | `300000` | Один раз предупреждать, когда контекст сессии достигает этого числа токенов (`0` = выключено). |
| `claudeCompanion.manageHooks` | `true` | Добавлять хуки в `~/.claude/settings.json`, пока VS Code открыт, и удалять их при закрытии последнего окна. |
| `claudeCompanion.port` | `47823` | Порт приёмника на `127.0.0.1`; все окна используют один выбранный слушатель. |
| `claudeCompanion.proxy` | `""` | Прокси для `api.anthropic.com`. Пусто = взять `HTTPS_PROXY` / `HTTP_PROXY` из окружения или из `env` в `~/.claude/settings.json`; `"none"` = подключаться напрямую; или URL прокси, например `http://127.0.0.1:8080`. |
| `claudeCompanion.trackNestedSessions` | `false` | Также отслеживать вложенные сессии (воркеры DeepSeek, `claude -p` из инструмента Bash). |
| `claudeCompanion.deepseekToggle` | `true` | Показывать переключатель DeepSeek в меню и в подсказке. |
| `claudeCompanion.deepseekInStatusBar` | `true` | Пока маршрутизация DeepSeek включена, дописывать в статус-бар баланс и расход воркеров за сегодня: `DS $3.42 (−$0.18)`. |
| `claudeCompanion.deepseekScope` | `"project"` | Какой файл настроек правит переключатель: `"project"` (`.claude/settings.local.json` первой папки) или `"user"` (`~/.claude/settings.json`). |
| `claudeCompanion.deepseekScript` | `""` | Путь к скрипту `claude-ds`; пусто = `<каталог Claude>/deepseek/claude-ds.mjs`. Скрипт запускается собственным Node расширения, поэтому в PATH его добавлять не нужно. |

## Команды

| Команда | Что делает |
|---|---|
| `Claude Companion: Меню` | То же меню, что по клику на статус-бар (сначала сессии, затем действия). |
| `Claude Companion: Лимиты` | Полный отчёт: каждый лимит с полоской, темпом и прогнозом, баланс DeepSeek и расход воркеров. |
| `Claude Companion: Обновить лимиты` | Перечитывает данные Claude и DeepSeek сейчас. |
| `Claude Companion: Проверить звуки` | Проигрывает звуки «выполнено», «ждёт» и «ошибка» по очереди. |
| `Claude Companion: Установить хуки` | Записывает HTTP-хуки в `~/.claude/settings.json` для текущего порта. |
| `Claude Companion: Удалить хуки` | Удаляет только записи Companion, сохраняя всё остальное. |
| `Claude Companion: Переключить DeepSeek` | Включает или выключает маршрутизацию DeepSeek для новых чатов (запускает `claude-ds`); это же первый пункт меню. |
| `Claude Companion: Диагностика` | Отчёт о состоянии: версии, хуки, порт и роль лидера, живые окна, хранилище сессий и кэш использования. |

## Установка из .vsix

Требования: VS Code 1.100 или новее, официальное расширение **Claude Code** и выполненный вход в Claude Code CLI (для лимитов подписки нужен вход в подписку Claude).

```bash
code --install-extension claude-companion-0.1.0.vsix
```

Перезагрузите окно. Хуки устанавливаются при активации. Для статусов во вкладках при первом запуске правится расширение Claude, и VS Code попросит ещё одну перезагрузку. Для удаления достаточно убрать расширение — его скрипт `vscode:uninstall` удалит записи хуков.

Сборка из исходников:

```bash
python scripts/gen-assets.py                 # шрифт, значок и звуки (детерминированно)
python scripts/build-vsix.py . 0.1.0 claude-companion-0.1.0.vsix
node --test "test/**/*.test.js"
```

`scripts/release.ps1` (Windows) поднимает версию, проверяет и собирает пакет, ставит его локально, ставит тег и публикует релиз на GitHub.

## Приватность

- OAuth-токен Claude читается локально из `~/.claude/.credentials.json` (или `CLAUDE_CONFIG_DIR`), отправляется только на `api.anthropic.com` в заголовке `Authorization` и никогда не попадает в логи. Companion **никогда не обновляет** токен — обновление провернуло бы вход самого Claude Code.
- Ключ DeepSeek читается из `DEEPSEEK_API_KEY`, `~/.claude/secrets/deepseek.json` или `~/.kimi-code/config.toml` и отправляется только на `api.deepseek.com`. Ключи никогда не логируются.
- Приёмник хуков слушает только `127.0.0.1`. Телеметрии, учётной записи и другого сетевого трафика нет; баланс, расход и лимиты кэшируются в глобальном хранилище расширения для следующего окна.

## Решение проблем

- **В статус-баре ничего нет.** Запустите `Claude Companion: Диагностика`: она покажет, установлены ли хуки, кто лидер, какие окна зарегистрированы и что лежит в хранилище.
- **Порт занят.** Возможно, `127.0.0.1:47823` держит другой процесс; измените `claudeCompanion.port` и перезагрузите окно. Все окна подхватят новый порт, а хуки будут перезаписаны.
- **Запросы лимитов не проходят через прокси.** Укажите URL прокси в `claudeCompanion.proxy` или оставьте поле пустым, чтобы взять `HTTPS_PROXY` / `HTTP_PROXY` из окружения или из `env` в `~/.claude/settings.json`. Значение `"none"` включает прямое подключение. Баланс DeepSeek всегда запрашивается напрямую.
- **CLI печатает «hook failed».** Хуки установлены только пока работает окно Companion; после падения они удаляются при следующем запуске VS Code. Если VS Code надолго закрыт, выполните `Claude Companion: Удалить хуки`.
- **Звуки не слышны.** Проверьте настройки звуков и запустите `Claude Companion: Проверить звуки`. На Windows WAV-файлы проигрываются через PowerShell `SoundPlayer`, на macOS — через `afplay`, на Linux должен быть установлен `paplay`.
- **Сессии нет в меню.** Сессии других окон VS Code показаны только для справки (открыть их здесь значило бы запустить второй CLI на той же сессии). Вложенные сессии скрыты, пока не включена `trackNestedSessions`. Сессия исчезает через 12 часов после последнего события.

Лог работы: **Вид → Вывод → «Claude Code Companion»**.
